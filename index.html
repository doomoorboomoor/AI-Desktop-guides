    How to use the packs with New+

    1. Download and extract the whole ZIP. Use the complete collection link or an app's separate ZIP card, then extract to a normal folder. Do not run scripts inside a ZIP preview.
    2. Enable PowerToys New+. Open PowerToys Settings and enable New+. Reading the guides requires neither PowerToys nor Python.
    3. Install the templates. Read the extracted README, then run Install-NewPlus-Templates.cmd. It skips existing same-named entries. To refresh matching entries with backups, run .\Install-NewPlus-Templates.ps1 -Overwrite from the extracted folder.
    4. Or copy selected entries manually. Choose New+ → Open templates in File Explorer and copy the desired items from NewPlus-Templates/ into that folder. Copy its contents, not the enclosing directory.
    5. Create a guide or workspace. Right-click an empty area in your destination folder, choose New+, then select a complete guide, an editable source project, an Atlas workspace, or the full library. New+ creates a copy.
    6. Edit and rebuild when needed. In an editable guide project, change content/guide.md and guide.config.json, then run Build-Guide.cmd. Python 3.9+ is needed only for rebuilding. The full library has Build-Library.cmd for rebuilding every guide and the master from its saved Markdown sources.

    #Old/ stores previous revisions; #Temp/ stores temporary work. They are not active source directories. Optional dated templates require New+'s filename-variable setting; variables change names, not file contents. The installer does not enable settings, sign into AI applications, or connect accounts.
