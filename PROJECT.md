# AI Desktop Reference Library Baseline

Revision: collection-v3-2026-10-31

## Purpose
Maintain complete, standalone reference manuals for the seven applications
named in Authoring/applications.json and matching New+ templates.

## Authoring authority
- Numbered guide files in #Source/ own instructional text.
- Authoring/config/ owns display metadata, not competing policy.
- Original uploads and #Old/ are historical snapshots.
- Rendered HTML and packaged template copies are derived artifacts.

## Required structure and verification
Preserve each manual's 12-section order and the shared instructional text.
Keep examples complete, scope native features accurately, and preserve
source dates unless the claims are actually reverified.
Rebuild with Build-Library.py; check links, source hashes, code copying,
keyboard navigation, print sources, and ZIP contents before distribution.

## Distribution
The master page links to the stable Google Drive file provided by the owner.
Rebuild and validate before replacing its ZIP bytes. Do not install apps,
connect accounts, or run New+ installation as part of a documentation build.
