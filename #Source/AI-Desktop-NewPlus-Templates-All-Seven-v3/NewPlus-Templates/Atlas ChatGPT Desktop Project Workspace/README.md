# Atlas ChatGPT Desktop workspace

Root `PROJECT.md` is this workspace's project-policy SSOT. The task,
domain context, initial handoff, and a separate example answer are complete.
`reference/guide.md` and `reference/chatgpt-desktop.html` contain the full manual as
derived reference snapshots, not competing workspace policy.

1. Create this folder with New+ and select it in ChatGPT Desktop using that app's supported project/file-access surface.
2. Read the root baseline, context/documentation.md, tasks/onboarding.md, and HANDOFF.md.
3. Confirm revisions and missing context, then draft outputs/onboarding-guide.md.
4. Inspect every task acceptance item and update HANDOFF.md with checks actually performed.
5. Resume by rereading those saved files. Do not assume chat synchronization.

The expected answer under examples/ is illustrative; it is not an approved output.
The template does not install ChatGPT Desktop, configure servers, enable hooks, or authorize accounts.
For OpenClaw, configure/select an intentionally dedicated agent workspace separately;
do not replace an established agent's persona or preferences with fictional examples.

Use #Old/ for history and #Temp/ for scratch work. See the complete reference
manual for platform-specific loading and native instruction semantics.
